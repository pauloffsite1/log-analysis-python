Log Data Analysis Project

This project looks at login activity data to identify unusual patterns, such as repeated failed login attempts.

Objective

The goal was to explore how basic data analysis can help detect potential security issues like brute-force login attempts.

Tools Used
Python (pandas)
CSV data
What I Did
Loaded and explored login data
Counted failed login attempts per user
Identified users with repeated failed logins
Reviewed activity by IP address
Key Findings
Some users showed repeated failed login attempts, which could indicate suspicious behavior
Certain IP addresses had higher activity than others
What I Learned

This project helped me understand how simple data analysis techniques can be used to identify patterns in system activity. It also gave me hands-on experience working with data using Python.
